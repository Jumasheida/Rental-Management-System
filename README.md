# Rental Management System

A web-based Rental Management System built with HTML, CSS, and JavaScript to help landlords organize rental properties, manage tenant records, and track rent payments efficiently.

## About the Project

The Rental Management System is a web application designed to simplify rental property management. It aims to help landlords organize property information, maintain tenant records, and manage rent payment information in one place.

This project demonstrates how web development technologies can be used to address a real-world business problem.

## Problem Statement

Managing rental properties manually can be time-consuming and challenging. Landlords may struggle to maintain accurate tenant records, monitor rent payments, and organize property information.

This project aims to provide a simple digital solution to make rental management more organized and accessible.

## Features

- Tenant record management
- Rent payment tracking
- User-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Getting Started
Follow the instructions below to set up and run the Rental Management System on your computer.

### Prerequisites

- A modern web browser
- Visual Studio Code

### Installation and Usage

1. Clone this repository:

   `git clone https://github.com/Jumasheida/Rental-Management-System.git`

2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open it in your browser, or use the Live Server extension if appropriate for your project.
